videodec: CF2 Add dump YUV in dw 3 mode. [1/1]

PD#SWPL-134504

Problem:
Dumping YUV was not supported in DW 3 mode previously.

Solution:
Setprop: setprop vendor.media.mediahal.videodec.dump_yuv "0 0 5"
The first value is the dump ID, with a default value of 0.
The second value is the starting frame for dumping, with a default value of 0.
The third value is the total number of frames to be dumped,
with a default value of 5.

Functionalities provided:

Dumping YUV in DW3 mode.
Specifying which channel requires YUV data dumping (supports multi channel).
Specifying the start frame and the total number of frames to be dumped.
The dumped file name includes the aligned width and height, eliminating the
need for additional alignment calculations when viewing the YUV data,
providing convenience and clarity.

Verify:
Android U + ohm
